# AIR BODY GYM 予約サイト

お客さんがアカウントなしでパーソナルトレーニングを予約できるサイトです。

- お客さん用：https://airbodygym.github.io/
- 管理画面：https://airbodygym.github.io/admin.html

- `index.html` … お客さん用（予約・マイページ・プラン申し込み）
- `admin.html` … トレーナー用の管理画面（予約一覧・受講記録・チケット有効化・設定）
- データは Supabase（プロジェクト `airbody-yoyaku`）に保存されます。

## しくみ

- お客さんは初回の予約・申し込み時に専用の「マイページURL」（`?me=...`）を受け取り、それで自分の予約とチケット残数を確認します。
- お客さんの名前や連絡先はトレーナーだけが見られます。空き状況として公開されるのは「どの枠が埋まっているか」だけです。
- トレーナーごとに曜日別の勤務時間と臨時の休みを設定でき、予約は勤務時間内の枠だけ受け付けます。
- 管理画面は最初に登録した1人だけが管理者になります。
- `assets/common.js` の公開キー（anon）はブラウザに置く前提のキーです。データの保護はデータベース側のアクセス制限で行っています。
